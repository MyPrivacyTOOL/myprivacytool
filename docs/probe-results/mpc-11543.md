## Web (9 of 9 probed, 9 found)

`https://api.myprivacytool.io/whoami-extra` from that page and read `navigator.userAgentData` there. This proves the data path the extras use.
It does **not** prove the on-page card: `VITE_WEB_EXTRAS` is off, and the "Extra connection checks" card is absent from the live page, as designed.

## Email (4 found)
Method: the production module `workers/scan-report/lib/emailExtras.js` (`runEmailExtras`) was run locally on one `+` alias of the
hello@ test address. **No email was sent and the live report pipeline was not exercised**: `EMAIL_EXTRAS_ENABLED` is off in production and
stays off (owner decision 2026-11-27), so no `extra-email.*` signal rows exist to read. The in-process flag was set only inside the one command.

owner's Mac with normal DNS access (a local Claude session started for this, result relayed to this session; not re-run here), which returned
all four. The second run supersedes the first for the two DNS ids.
